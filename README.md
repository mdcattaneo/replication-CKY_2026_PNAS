# Replication: Cattaneo, Klusowski and Yu (2026, PNAS)

Replication files for simulation and empirical results.

## Replication

Requires R, make, a C++ compiler, Cairo support, Liberation Sans fonts, and `sha256sum`.
Run from the repository folder:

```sh
Rscript CKY_2026_PNAS--simuls.R
Rscript CKY_2026_PNAS--empapp.R
Rscript CKY_2026_PNAS--plots.R
```
